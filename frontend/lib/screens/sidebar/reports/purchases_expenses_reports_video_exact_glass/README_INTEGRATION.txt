PURCHASES AND EXPENSES REPORTS - INTEGRATION

Copy this folder to:

lib/screens/sidebar/reports/purchases_expenses_reports/

Import:

import 'package:YOUR_APP/screens/sidebar/reports/purchases_expenses_reports/purchases_expenses_reports_page.dart';

Open the module with:

const PurchasesExpensesReportsPage()

If your main Reports Center controls back navigation, use:

PurchasesExpensesReportsPage(
  onBackToAllReports: () {
    // switch back to your main Reports Center
  },
)

This package intentionally contains only the content shown in the uploaded video:

Purchases and Expenses
- Purchases by Vendor
- Purchases by Item
- Expense Details
- Expenses by Category

No additional report, filter, summary card, sample row, or form field was added.
